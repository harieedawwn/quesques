# Ôn tập Hóa học 11 — Nitrogen, Sulfur & các hợp chất

Trang web tĩnh (1 file `index.html`), chạy trên laptop, tablet, iPhone, Android. Không cần cài đặt, không cần máy chủ.

**Nội dung:** 121 câu — 96 trắc nghiệm, 9 đúng – sai (4 ý/câu), 16 trả lời ngắn — chia theo 4 chuyên đề, có đáp án và lời giải.

**Tính năng**
- *Luyện tập*: biết đáp án ngay; trắc nghiệm và trả lời ngắn được thử lại; đúng – sai có lời giải từng ý.
- *Thi thật*: tính giờ, đánh dấu câu cần xem lại, chấm thang 10 (đúng – sai chấm theo từng ý: 1 ý = 0,1; 2 ý = 0,25; 3 ý = 0,5; 4 ý = 1 điểm).
- Lọc theo dạng câu hỏi, chuyên đề, chọn số câu ngẫu nhiên, xáo câu / xáo đáp án.
- *Xem đáp án & in đề*: tra cứu toàn bộ đáp án + lời giải, có ô tìm kiếm, in hoặc lưu PDF.
- Công thức hóa học hiển thị bằng chỉ số trên/dưới thật (H<sub>2</sub>SO<sub>4</sub>, NO<sub>3</sub><sup>−</sup>…).

**Bật GitHub Pages:** Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
